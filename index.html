建议现场展示顺序

约 5 分钟
  1. 提出问题解释单一策略在不同市场状态下的局限。
  2. 展示数据与假设切换数据质量、列映射与费用参数，先说明证据来源。
  3. 运行与比较展示规则权重或 DQN 动作 Q 值，再比较净值与回撤。
  4. 挑战结论增加成本，检查参数与时间分段敏感性。
  5. 交付研究记录保存行情、参数与模型权重，导出决策记录和报告。

导师可能追问

研究备忘
平台是否已经运行论文中的深度强化学习？

平台支持真正的已训练 DQN 前向推理：加载受控权重 JSON 后，网络输出 Q 值并选择策略。参考权重是本项目新训练的模型，不是原论文权重；原论文结果仍未独立复现。网页只推理，不在线训练。

如何避免回测看见未来？

历史窗口生成信号，下一周期执行；进一步需检查样本划分、特征标准化与训练数据边界。

动态集成一定优于单策略吗？

不一定。应在相同成本与区间下比较，并结合时间分段与参数敏感性，允许呈现失效情境。

本次工程建设有什么可验证贡献？

统一数据检查、回测假设、六策略对比、稳健性分析与实验导出，形成可操作、可追溯的研究流程。

建议后续建设

接入经授权的复权行情；扩展参考 DQN 的数据与训练验证；进行严格训练 / 验证 / 测试划分及多随机种子消融；加入真实交易约束；在受控后端提供用户隔离与云端实验存储。
